# Data Analysis Practicum

## Overview
This repository serves as a static archive of past academic assignments and empirical exercises focused on econometric modeling, data cleaning, and applied economic analysis. 

## Status & Reproducibility ⚠️
**This repository is strictly a read-only code backup and portfolio reference.**

The scripts contained within these directories are **not reproducible**. The original datasets (such as household surveys, census data, and macroeconomic time series) required to execute the code are not hosted in this repository and are no longer available. 

## Structure
The archive is organized by subject and contains code for topics such as:
* Econometrics
* Microeconomics
* Economic Development
* International Trade
* Spatial and Environmental Economics
